Schema notes & known boundaries +

What is supported

Canonical IDE 1.x PascalCase triggers, command and agent actions, optional matchers, timeout seconds, enabled state, and PermissionRequest command-only validation. Stop is not treated as a blocking trigger.

What is not simulated

Kiro's runtime regex implementation, actual tool IDs in your installation, STDIN payload shape beyond the event subject, command output, exit codes, confirmation prompts, and hook ordering.
